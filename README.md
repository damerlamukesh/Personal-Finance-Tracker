# 💰 Personal Finance Tracker

A simple and intuitive personal finance management application built with **React.js and Tailwind CSS**. It helps users track their income and expenses, monitor spending habits, and manage their finances through a clean and responsive interface.

## ✨ Features

- **Income & Expense Tracking** – Record and manage daily financial transactions.
- **Transaction Management** – Add, view, edit, and delete transactions.
- **Financial Overview** – Get a clear summary of income, expenses, and balance.
- **Transaction Categorization** – Organize transactions by category.
- **Responsive Design** – Access the application across desktop and mobile devices.
- **Interactive Dashboard** – View financial information in an organized format.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/damerlamukesh/Personal-Finance-Tracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Personal-Finance-Tracker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
